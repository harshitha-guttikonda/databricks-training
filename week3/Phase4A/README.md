\# Phase 4A - Bucketing and Customer Segmentation



\## Overview



Phase 4A focuses on customer segmentation techniques using SQL and PySpark. Customers are grouped into different categories based on their spending patterns using fixed thresholds and quantile-based bucketing. This helps businesses understand customer value and create targeted marketing strategies.



\## Objectives



\- Segment customers based on spending.

\- Apply bucketing techniques.

\- Compare different segmentation methods.

\- Analyze customer distribution.
