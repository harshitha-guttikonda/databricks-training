\# Phase 2 - SQL Queries and PySpark Transformations



\## Overview



Phase 2 focuses on performing data analysis using SQL queries and implementing the same operations using PySpark DataFrame APIs. This phase introduces the fundamental concepts required for processing structured data and demonstrates how SQL operations can be translated into PySpark.



\## Objectives



\- Understand relational data processing.

\- Practice SQL query writing.

\- Learn equivalent PySpark transformations.

\- Analyze customer and sales datasets.



\## Topics Covered



\### SQL

\- SELECT Statement

\- WHERE Clause

\- ORDER BY

\- GROUP BY

\- Aggregate Functions

\- INNER JOIN

\- Filtering Records



\### PySpark

\- Reading CSV files

\- DataFrame operations

\- Filtering records

\- Selecting columns

\- Joining DataFrames

\- Aggregation

\- Sorting results
