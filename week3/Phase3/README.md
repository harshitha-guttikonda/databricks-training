\# Phase 3 - Data Ingestion and Data Cleaning



\## Overview



Phase 3 focuses on loading datasets into Apache Spark and preparing them for analysis. The objective is to clean the data, remove inconsistencies, and perform basic exploratory transformations before further processing.



\## Objectives



\- Load CSV datasets into PySpark.

\- Clean and validate the data.

\- Remove duplicate records.

\- Handle missing values.

\- Prepare clean datasets for analytics.



\## Topics Covered



\### Data Ingestion

\- Loading CSV files

\- Reading datasets using Spark

\- Schema inference



\### Data Cleaning

\- Removing duplicate records

\- Removing null values

\- Filtering invalid records

\- Checking schemas

\- Sorting records



\### SQL

\### PySpark
